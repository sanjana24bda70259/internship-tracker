# Internship Tracker — Requirements

## Problem Statement

Students often track internship applications using spreadsheets or notes, making it difficult to manage deadlines, interviews, and application status.

The Internship Tracker will provide one centralized dashboard to manage internship applications.

## MVP Features

- [ ] User registration and login
- [ ] JWT authentication
- [ ] Create internship application
- [ ] View internship applications
- [ ] Update internship application
- [ ] Delete internship application
- [ ] Dashboard with application statistics
- [ ] Search applications
- [ ] Filter applications by status

## Application Status

- Wishlist
- Applied
- Assessment
- Interview
- Offer
- Rejected
- Withdrawn

## Application Information

Each application will contain:

- Company name
- Job title
- Location
- Internship type
- Application date
- Application deadline
- Application URL
- Status
- Salary/Stipend
- Notes
- Recruiter information

## Future Features

## User Stories

### Authentication

- As a student, I want to register so I can create an account.
- As a student, I want to log in so I can access my applications.
- As a student, I want my applications to be private.

### Application Management

- As a student, I want to add an internship application.
- As a student, I want to edit an application.
- As a student, I want to delete an application.
- As a student, I want to filter applications by status.

### Dashboard

- As a student, I want to see my total applications.
- As a student, I want to see interviews and offers.
- As a student, I want to see upcoming deadlines.
